We will be building agentic AI using langchain.

Steps done so far:
    1. install UV
    2. in the command prompt : "UV init", this uv init creates a pyproject.ml file. 
    3. Update the pyproject.ml file with the all the dependencies you need for the project.
    4. in the command prompt : "UV sync", this creates a virtual environment and installs all the packages mentioned in the pyproject.ml
    5. Activate the virtual environment
